## 题字补证

正面入口“文萃李唐”和顶层“鸛雀樓”仍按此前已定位的实景照片。入口柱联此前留空，此轮查到[西安晚报记者解维汉2006年现场报道](https://news.sohu.com/20061001/n245627258.shtml)，明确一楼西门柱联为“凌空白日三千丈，拔地黄河第一楼”。模型按传统右上联、左下联补入。该报道能证明柱联文本，但尚未独立确认模型“文萃李唐”立面与报道西门的方位对应；此处挂置归属保留待核。书法笔迹和雕边不是摹本；其他方向不复制。

## 仍不能宣称相同的部分

主要轮廓、层高比例、出檐宽度及抱厦交接仍需同角度复核。实景斗栱和彩画明显比模型更丰富；屋脊、鸱吻、飞檐曲线仍是程序化近似。台基侧翼、其他方向、隐藏相交结构及精细格心没有测绘依据。并排页面刻意保留这些差异可见，不用落日天空、滤镜或景观遮挡来替代建筑造型。

- `npm run check`、`npm run build` 均通过；27,680个装配构件、8个材质批次、2,426,604个非索引顶点，全部动画结束时间不超过0.953。
- 确定性散列：`41a2f4d3325d2b7719bfc4f151dc554b8bf671afe73c3323927106efbbfa0ce8`。检查包括屋瓦法向朝上、两层平座相对宽度、顶平座大于顶檐及主顶高度约束。这些是实现回归检查，不能证明实景还原程度。
- 最新生产构建已在并排页实际观察：整体三组明层、四道主要檐线、两层近等宽平座与长短登台阶均可见。入口近景可见深色隔扇、向上起拱门头、右读横匾与两条柱联。
- 并排观察仍明显可见：实景斗栱与彩画更密，模型石台和栏杆偏干净，门窗与屋脊装饰仍为简化。未进行精确相机标定，不能通过并排像素直接认定真实尺寸。
- 构建保留单个JavaScript包大于500KB提示（gzip约224KB）；本轮没有长期GPU或真实手机性能验收。
- 外观状态保持 `VISUAL_REVIEW_REQUIRED`。用户尚未验收，旧报告中艺术演示推荐不升级为外观认可。
