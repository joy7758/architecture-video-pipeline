## 一句话下单

例如：**“开工天安门，现存版本，竖屏，30秒。”** 总指挥补齐城市、实体与展示范围；确有同名或年代歧义时询问。天安门目前只是示例，本轮以现有鹳雀楼检验本地出片工位。

默认创作约定：现存外观的程序化艺术重现、9:16 竖屏、目标 1080×1920 / 30 fps / 24 秒、静音、程序化纹理。未指定的平台沿用通用 H.264 MP4。720p 只能标明为预览规格。更改这些约定会写入任务单。

## 工位与返工

| 顺序 | 负责人 | 必须交付 | 失败时 |
|---|---|---|---|
| 0 下单与推荐 | 总指挥 + 独立推荐审查 | 建筑实体、版本、范围、视频规格、推荐条件 | 补足决定性歧义 |
| 1 资料发现 | 资料发现智能体 | 来源包、正面与可判读进深的另一视角、外观事实与未知项、许可范围 | `NEEDS_REFERENCE`，继续寻找资料 |
| 2 建筑解读 | 建筑规划智能体 | 比例、部件树、装配依赖、简化清单、镜头脚本 | 回到对应来源；不能把猜测填成实测 |
| 3 施工 | 使用指定 skill 的编码智能体 | 独立建筑 adapter、建成轮廓、进度接口、可运行场景 | 按问题 ID 修复具体部位 |
| 4 检查 | 独立视觉审查 + 技术检查 + TITMAS 接入 | 代码/模型/图片哈希绑定的检查结果；TITMAS 独立原始回执 | 未过项目返回来源/规划/施工；保留失败 |
| 5 出片 | 视频工位 | 固定帧采样 MP4、封面、关键帧、渲染清单 | 检查加载、画幅、缺帧、镜头与文字 |
| 6 交付 | 总指挥 | 视频、封面、说明文案、来源说明、QA 摘要 | 未通过最终检查只交预览并列缺口 |
| 7 发布 | 用户 | 用户自行选择平台并发布 | 不自动上传、发帖或部署 |

工位 4 在渲染前检查模型；工位 5 后还要复核真正的 MP4。技术 PASS、视觉 PASS、TITMAS 验证结果分别记录。TITMAS 对执行证据的核验不替代建筑辨识度审查。

## 总指挥运行方式

1. 从 `agent-index.json`、本文件和 [工位提示](roles.md) 进入。读取目标 job 的状态，使用 [CLI](CLI.md) 建单或恢复。
2. 独立工位用当前对话的子智能体执行，并明确写入文件所有权。用户另行要求新任务时才创建侧栏任务。所有代码修改归本应用；外部基础设施仅经已核实的接口复用。
3. 资料冻结后再施工。先看建成形体，再做装配时序与镜头。不要将鹳雀楼仅改名成另一座建筑。
4. 可独立的技术检查、资料补核与文案准备并行。建模结果未产出前，视觉工位不能签发最终结论。
5. 检查提出明确的 `issue_id`、严重度、工件和修复要求。修复使相关检查及其下游结果失效；必须对更新后的 hash 重验。两轮仍失败时总指挥定位原因，避免盲目重复。
6. 生成预览可帮助发现问题。只有全部必要门禁接通并有真实证据时才能称 `READY_FOR_USER_REVIEW`；发布仍由用户操作。
7. 每次完成或遇到实质阻塞，更新 job 与驾驶舱本地报备。状态由本项目工件决定；驾驶舱只引用。

这是一条由当前对话驱动的本地工作流。CLI 提供任务和证据门禁，施工与研究由智能体完成。没有后台定时任务、无人值守常驻服务或外部模型服务的隐式接入。

## 固定快照出片

运行 `node pipeline/snapshot-app.mjs`，获得经输入哈希复核的新 app 快照路径。在该路径执行 `npm run check`、`npm run build`，然后用独立端口启动 preview。通过 `node pipeline/render-video.mjs --app-root <快照app> --config pipeline/video/guanque-pilot-wide.json --url http://127.0.0.1:<端口>/` 出片。详见 [视频工位](video/README.md)。快照保留源码与锁文件，本机已安装依赖通过符号链接复用；不声称完整环境隔离或跨GPU像素一致。

并行施工修改原app不影响固定快照；新版本需要重新建快照和验收。`SOURCE_HASH_CHANGED` 的失败运行保留，不能升级为通过。

## 资料和模型合同

- 资料来源优先建筑管理机构、官方文化机构、建筑设计/修缮机构；网页有出处仍须记录访问时间与实际观察内容。
- 每项关键判断记录为 `observed`、`source_reported`、`artistic_choice` 或 `unknown`。照片只能支持看得到的外观；内部结构、背面与尺寸不能由单张图推断为事实。
- 参考图片默认 `REFERENCE_ONLY`，不出现在公开视频。用户补充资料与独立核实来源分开标注。
- 模型合同包括 `adapter_id`、几何入口、固定 seed、构件组、共同尺寸、装配依赖、`progress` 范围、相机和牌匾可见性。现有 adapter 仅为 `guanque`。
- 当前逆向效果是装配时间线倒放。真正的分层爆炸图需要为构件组另设空间位移与承接关系，不能以倒放装配冒称已实现。
