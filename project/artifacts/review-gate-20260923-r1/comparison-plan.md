## 盲评与 gold

两位实际指定的独立标注者先逐项标注，至少一位能依据建筑/镜头判据复核；另指定独立裁决者处理争议。不得让被测 A0/C 或对应施工作者成为唯一 gold 来源。尚未指定或执行任何标注者，不虚构参与记录。

标签需记录具体条款、严重度、原始文件摘要、帧时间/局部位置、可见事实、推断、资料限制、分歧与裁决理由。相机未标定时不发明实测尺寸或像素真值；无法裁定的项保持 UNKNOWN/CONFLICTED。

模型仅见匿名 case、全部必需资料、共同 rubric、工具和预算；看不到 gold、预期缺陷位置、对方答案、split 或公开倒查答案。评卷者先查看匿名标准化结果与原始证据，不看 A0/C 身份、成本和耗时，评分锁定后再审计完整轨迹。若轨迹泄露拓扑，必须记录盲评限制。

## 先比较错误放行，再看实用性

模型原始结论与共同确定性门禁后的结论分别保存，才能看出“模型漏检被门禁拦住”，避免误认模型已经发现缺陷。

1. **关键误放优先**：gold 关键 FAIL/REJECT 被给 PASS 必须逐例记录。selection 或 heldout 观测到任何关键误放，均不能推荐该方案自动放行。零观测错误也不等于真实错误率为零。
2. **防全部拒绝与全部弃权**：在 gold PASS 上明确误拒不超过 25%；在可判 PASS/FAIL 上不必要弃权不超过 25%；合格正例被有效接受至少 50%。UNKNOWN 不隐藏进误拒或准确率。以上为本计划的试点筛选值，不是生产 SLA，可在 selection 前版本化修订，不能看结果后改值。
3. **质量与相关错误**：逐项混淆矩阵、有效覆盖、证据定位、更新失效、合理 UNKNOWN、三次重复翻转、双方及 C 内部共同漏检。记录共享模型、摘要、帧集和 rubric；角色数不代表证据独立数。
4. **真实代价**：全拓扑 token、费用、延迟、计算时间、人工分钟、超时与重试。低成本不能抵消关键误放，主观综合分不能隐藏失败。

覆盖率分母是冻结的全部必需项；有有效、同版记录才计覆盖，同时单列 FAIL、UNKNOWN、CONFLICTED。100% 覆盖不证明判断正确。N/A 只能来自事先冻结的范围，不能由审查者临场跳过难项。

所有失败、超预算、缺结果都保留在分母。按 scope、split、真实/合成类型给原始计数、配对差值与不确定性；重复运行按 case 聚类，家族相关性必须保留。可报告二项区间和家族聚类重采样；家族太少时只给描述性结果，拒绝显著优越声明。

## 如何决定

- A0 满足所测范围要求、C 无稳定可复核增益：保留更简单 A0 和逻辑职责边界，不继续拆 agent。
- C 在同预算 selection 有明确收益，heldout 未反转，且误放、误拒、弃权与代价可接受：仅推荐在该本地范围继续验证 C。
- 两者都不可靠：保留人工审查或收缩承诺范围。结果冲突、保留集不足或代价取舍无法裁定时记录 `INCONCLUSIVE`。
- 现有 TITMAS 合同能表达结果时优先复用；只有可复现、跨场景的通用合同缺口才提出最小核心扩展。不能从这次本地结果直接注册 DCell 或声明线上服务成熟。

这些配额不是统计功效证明；每类八个保留 case 和少量建筑不能证明一般优越、跨建筑可靠或生产可用。即使 C 表现较好，也只能支持继续/停止当前有界路线。
