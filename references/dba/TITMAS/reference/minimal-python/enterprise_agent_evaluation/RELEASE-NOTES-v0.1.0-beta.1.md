# TITMAS Enterprise Agent Review v0.1.0-beta.1

## 首个商业测试版

这是一个面向企业智能体部署方案的本地实战评测工具：使用冻结的合成业务场景、运行事实、Evidence Reference（证据引用）、人工裁决槽位和红线规则，帮助团队判断一套方案是否值得进入下一步受控试用。

### 本版新增

- 首个真实 Provider：阿里云百炼直接模型调用（`BAILIAN_DIRECT_MODEL`）；
- 青岚家居 6 个合成企业客服案例，各运行两次；
- 标准四行输出合同与零自动重试；
- 独立红线判断、政策依据检查、人工升级统计、成本与延迟记录；
- 基于同一个 canonical result 的 JSON 和独立 HTML 报告；
- 脱敏公开样例与本地三分钟快速开始。

### 已观察到的本次结果

- 模型：`qwen3.7-max`（`ROLLING_ALIAS`；固定快照 `qwen3.7-max-2026-05-20` 在当前账号/地域不可用，已保留该限制）；
- 12/12 次合成调用成功并满足输出合同；
- 红线逻辑：`PASS`；Evidence Reference 捕获：`PASS`；
- 模型估算成本：`¥0.089112`；证据等级：`E1`。

### 当前限制

- 仅使用合成案例；未处理真实企业客户、个人、机密或生产数据；
- 自动暂定评估不等于人工最终裁决，推荐指数保持 `INCOMPLETE`；
- 不是生产就绪、客户验证、长期稳定性验证、安全/合规认证或 SLA；
- Dify 仅完成离线合同验证，未进行真实调用；
- Evidence Reference 不等于 Truth，评测不产生执行权限。
